The ISBAR Framework

Structured clinical communication for patient safety

IIdentify
SSituation
BBackground
AAssessment
RRecommend
I — Identification
Patient name, MRN, bed number, age, gender, your name and role
S — Situation
What is happening now? Current complaints, symptoms, vital signs
B — Background
Medical history, current medications, allergies, recent procedures
A — Assessment
Clinical impression, stability status (Stable/Unstable/Critical)
R — Recommendation
Action plan, requested tasks, follow-up, escalation needs
Why ISBAR Matters
Standardized communication reduces clinical errors by up to 30%. ISBAR ensures every handover contains critical information in a consistent, scannable format.

Role-Based Access Control

Four-tier permission system ensuring data security and appropriate access

U

Staff

Basic clinical access
  • View assigned patients
  • Submit ISBAR reports
  • Check in/out of shifts
  • View own activity
U

User

Department-level access
  • All Staff permissions
  • View department patients
  • Manage department resources
  • View department activity
  • Access department records
A

Admin

Full system management
  • All User permissions
  • User management
  • Form builder access
  • Check-in logs
  • Attendance reports
  • System settings
  • Impersonate users
SA

SuperAdmin

Complete system control
  • All Admin permissions
  • Create/manage admins
  • System-wide settings
  • Database management
  • API configuration
  • Security audit logs
