📖 Bahire Hasab Algorithm
Agebat (New Year Calculation):
Amete Alem = (Amete Mihaaret * 19) mod 4
Kidase = (Amete Mihaaret * 7) mod 18
Bahiye Hasab = Kidase + Amete Alem + 15
Metkih (Easter): Bahiye Hasab mod 30
Nebene = 1 if Metkih >= 15, else 0
Tnsae (Resurrection) = Metkih + 14 + Nebene
✨ This algorithm determines all movable Ethiopian holidays for any given year. The ISBAR system automatically calculates and displays these dates alongside Gregorian dates.
