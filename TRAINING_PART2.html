Role-Based Access Control

Four tiers of access ensuring data security and appropriate permissions

🛡

Superadmin

Full system access
  • All administrative functions
  • User management & PIN reset
  • System configuration
  • Data export & backup
  • Audit log access
🏛

Admin

Administrative access
  • Form builder & custom tabs
  • Dashboard mapping
  • Check-in log management
  • Attendance reports
  • Staff scheduling
🩺

User

Department head access
  • ISBAR form submission
  • Department activity view
  • Patient management
  • Resource tracking
  • Analytics (own dept)
👤

Staff

Basic clinical access
  • Check-in/out only
  • View own shift schedule
  • View department activity
  • Read-only dashboard
  • No admin functions

Security Features

Enterprise-grade security protecting patient data and system integrity

🔐

PIN Authentication

4-digit PIN verification for staff check-in with bcrypt hashing. PINs are never stored in plain text.

🛡

Role-Based Access

Four-tier permission system ensures staff only see data relevant to their role and department.

📊

Audit Logging

Complete audit trail of all user actions, check-ins, form submissions, and data exports.

🔒

Data Encryption

All data encrypted in transit (HTTPS) and at rest. Database backups encrypted with AES-256.

⏰

Session Management

Automatic session timeout after inactivity. Secure token-based authentication with refresh.

📝

Compliance Ready

Built to support Ethiopian healthcare data regulations and international patient privacy standards.

Quick Reference

Essential keyboard shortcuts and common workflows

Common Workflows

1. Log in → Select department → Check in with PIN
2. Dashboard → Click patient card → Fill ISBAR form
3. Admin → Form Builder → Create template → Publish
4. Schedule → Select week → Assign shifts → Export
5. Reports → Filter by dept → Generate → Download PDF

Tips & Best Practices

✅ Always check in at the start of your shift
✅ Complete ISBAR forms before handover
✅ Use the AI Dashboard for clinical insights
✅ Export schedules weekly for distribution
✅ Report any system issues to admin immediately
