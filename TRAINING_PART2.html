Plan the ward

Staff Schedule & Bed Allocation

Two tabs: "Shift Schedule" (weekly rostering) and "Bed Allocation" (staff-to-bed assignments).

🗓️

Shift Schedule

Roster
  • Pick a week + department; grid of staff × days
  • Shift types follow the department's base: 8H Morning/Afternoon/Night · 12H Day/Night · 4H six windows · On-Call (24–72H)
  • Assign: arm a shift button, then click empty cells (or use the cell dropdown)
  • Click an assigned cell to change or Remove Shift
🛏️

Bed Allocation

Wards
  • Assign staff to beds per day across a 30-day window
  • Today highlighted · weekends shaded
  • Manage Beds — add, activate / deactivate, delete beds
  • Filter by department, staff, or profession
📤

Export & Controls

Handover
  • Export as PNG image or Export as Excel spreadsheet
  • Lock the schedule to disable editing (applies to both tabs)
  • Change History — assigned / removed / changed with old → new shift
  • Legend: Today / Weekend / Holiday + shift color codes

Field Library

Components

04

Personalize the dashboard

Custom Tabs & Dashboard Mapping

Build your own dashboard tabs and connect form data to live cards.

📑

Custom Tabs

Tailored
  • Create tabs with a display name that appear on the Dashboard
  • View styles: Card · Table · List · Stack (compliance score ring, Yes/No/N-A chips)
  • Group records by a field; set retention — forever / 24h / 12h / 8h
  • Visible by department / profession; admins can remove tabs
🧭

Dashboard Mapping

Live Data
  • Map form fields to dashboard cards (display name, departments)
  • Map the status indicator field — values normalize to Stable / Subcritical / Critical
  • Supports code words: code green / yellow / red, stable, unstable…
  • Resource and Nursing Round mappings feed the Inventory & Round tabs

Mapping keeps the dashboard driven by real submitted data — no manual entry, everything reflects the latest reports.

05

Connect external systems

Integrations

Manage external system connections — EMR, lab systems, and more.

🤖

External Connections

Ecosystem
  • Presets: Bahmni EMR · OpenMRS · HL7 FHIR Server · Custom REST API
  • Fetch and sync patient data (name, gender, age, MRN, DOB…)
  • Field mapping — source field → target field
  • Sync settings: fetch patients, auto-sync, interval
🔧

Configuration

Setup
  • Base URL + auth type (basic / bearer)
  • Test connection before saving
  • Enable / disable with last sync status and time
  • Each connection keeps its own API key — AI features need internet, everything else works offline

Integrations keep the system extensible — new hospital tools plug in without rebuilding the platform.

06

Who's on duty

Check-In Logs

"Staff attendance history" — every clock-in and clock-out, searchable.

✅

Log Table

Record
  • Columns: Staff, Department, Shift, Check In, Check Out, Duration, Status
  • Check-in / check-out with Ethiopian date & time
  • Duration as "5h 30m"
  • Status: Active (pulsing) or Completed
🎯

Filters

Search
  • Search by staff name, profession, or ward
  • Department selector
  • Start & end date range
  • Clear Filters · 50 records per page

Check-In Logs are the source of truth behind Attendance Reports — accurate clock-ins make attendance trustworthy.

Track presence

Attendance Reports

"Staff attendance summaries" — compiled automatically from shift sessions.

📊

Period & Scope

Automated
  • Period toggle: Daily · Weekly · Monthly
  • Custom date range + department selector
  • Summary cards: Staff (count + active), Total Shifts, Total Hours
🧮

Breakdown

Metrics
  • Department Breakdown — hours bars per department
  • Individual Attendance table — Staff, Department, Shifts, Hours, Status

Shifts and hours are counted from check-in sessions — remind your team to check in every shift.

Create & Manage

Accounts

09

Keep the system healthy

Activity Log & Settings

The complete hospital audit trail and system-wide configuration.

📜

Activity Log

Audit
  • All activity types: Reports · Inventory Updates · Inventory Reports · Admin Actions · Staff Registered
  • Presets: 7D · 1M · 3M · 6M · 1Y · All
  • Stat cards, daily trend, top people & departments
  • Cleanup: delete records in a date range
🛠️

Settings

9 Tabs
  • Overview · Migration · Backup · Theme · Data · Security · Notifications · Audit Trail · Maintenance
  • System info: Node version, uptime, database, users, reports, disk
  • Auto-backup with retention · password policy · session timeout
  • Brand color, dark / compact theme · low-stock, expiry & shift alerts

Only admins can change settings — changes take effect immediately for all users.

10

Safe by design

Roles & Security

Role-based access with module permissions and a complete audit trail.

🛡️

Access Control

Control
  • Each role sees only its permitted modules (view actions)
  • Admin-only pages are hidden from other roles
  • Passwords stored securely hashed
  • User sessions protected with tokens
🤝

Shared Responsibility

Everyone
  • Never share accounts or passwords
  • Sign out on shared computers
  • Report lost credentials to IT immediately
  • Every report is traceable — reporter, shift & timestamp are logged

Security is a team effort — the audit trail protects staff and patients alike.
